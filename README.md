## 🚀 Running the Project

```bash
# 1. Install dependencies
npm install

# 2. Run the development server
npm run dev

# 3. Build for production
npm run build

# 4. Preview the production build
npm run preview
```

## 📸 Updating Profile Photos

To use your own photos:
1. Replace `public/profile.png` with your portrait photo.
2. Replace `public/about-profile.png` with a square headshot photo.
3. The website will automatically display your images without requiring any code changes!
